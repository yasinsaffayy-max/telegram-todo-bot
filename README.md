# 🤖 Telegram Todo Bot

یک ربات تلگرام برای مدیریت کارهای روزانه

## ✨ امکانات
- ➕ افزودن کار با ارسال متن
- 📋 نمایش لیست کارها
- ✅ علامت زدن به عنوان انجام‌شده
- 🗑 حذف کار
- 💾 ذخیره‌سازی در SQLite

## 🛠 تکنولوژی‌ها
- Python 3.10
- python-telegram-bot
- SQLite

## 🚀 اجرا
\`\`\`bash
pip install -r requirements.txt
echo "BOT_TOKEN=your_token_here" > .env
python bot.py
\`\`\`
